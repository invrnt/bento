## Deliver

1. `stream_aead.py` — `StreamingBlobCipher` implementing `BlobCipherPort` exactly per § Blob format v2: 36-byte header, HKDF per-file key, STREAM nonces with segment index and last flag, header as AAD, 1 MiB default segments, empty-file handling, deterministic output for identical params, `decrypt_file` that also accepts legacy v1 files (delegate to the existing adapter logic), `decrypt_range` that reads only the needed segments through the async reader and verifies each. Streams in constant memory (no whole-file reads).
2. `vault_crypto.py` — `VaultCrypto` implementing `VaultCryptoPort`: keyring generation/rotation/serialization (canonical JSON, base64url keys), HKDF subkeys per `KeyPurpose`, `BENV` envelope with purpose code and epoch, `seal_json`/`open_json` with zlib, header MAC (HMAC-SHA256, base64url, constant-time verify), recovery code (160-bit secret + 20-bit checksum, Crockford Base32, 9 groups of 4, alias normalization), recovery wrap/unwrap with AAD `vault_id`, device identity (X25519, `dev_<uuid4 hex>`), `BBOX` sealed boxes.
3. `pairing_crypto.py` — `PairingCryptoFactory` implementing `PairingCryptoFactoryPort`: SPAKE2_A/SPAKE2_B with `idA=b"bento-host"`, `idB=b"bento-guest"`; confirmations `HMAC(K, b"host-confirm"|b"guest-confirm")`; direction keys `HKDF(K, info="bento/v1/pairing/h2g"|"g2h")`; frames `0x03 || AES-GCM(key, nonce = 4 zero bytes || u64 counter, canonical JSON)` with strictly increasing counters and replay rejection; `sas()` 4 emojis from `HKDF(K, info="bento/v1/pairing/sas")` over a fixed, documented 64-emoji list (distinct, widely supported, no flags/skin tones); fallback keys via ephemeral X25519 + `HKDF(shared, salt=sorted(pubA,pubB), info="bento/v1/pairing/fallback-sas")`.
4. `key_store.py` — `WrappedFileKeyStore(directory, wrapping_key)` implementing `KeyStorePort` (AES-256-GCM, AAD = name, `0600` files, atomic replace, name validation `^[a-z0-9._-]{1,64}$`), `InMemoryKeyStore` for tests, and `load_wrapping_key(settings_env, data_dir)`: `BENTO_DEVICE_WRAPPING_KEY` (base64url 32 bytes) or create/read `data/secure/wrapping.key` with `0600` and return a flag telling callers it was file-based (for doctor warnings).
5. Export the new adapters from `adapters/security/__init__.py` without breaking existing imports.

## Required Tests

- Round trips for many sizes (0, 1, segment−1, segment, segment+1, several MiB), deterministic re-encryption with fixed params, every single-bit flip/truncation/extension/segment swap fails with `IntegrityError`, range decryption across segment boundaries equals the plaintext slice, constant-memory behavior on a large sparse file (sanity, not a benchmark).
- Envelope purpose/epoch mismatch fails; header MAC verifies and rejects edits.
- Recovery code format, normalization (`O→0`, `I/L→1`, spaces, lowercase), checksum rejection, wrong-code unwrap → `RecoveryCodeInvalidError`.
- Sealed boxes only open with the right identity and AAD.
- Pairing: same code → same keys/SAS on both sides; different code → confirmation failure; replayed or reordered frames rejected.
- Key store: file permissions, wrong wrapping key fails closed, atomic overwrite.
- Published known-answer vectors for HKDF/AES-GCM layouts in a JSON fixture generated by the tests themselves with fixed inputs, so future refactors cannot silently change formats.
