# Configurar Telegram en Bento

La configuración con bot (BotFather, servidor Telegram Bot API local, IDs de canales, webhook y claves en `.env`) **se eliminó**. Bento ahora se conecta a tu propia cuenta de Telegram escaneando un código QR, crea sus canales privados y cifra todo automáticamente. No hay nada que configurar a mano.

- Usuarios: [Conectar tu Telegram](user/es/conectar-telegram.md) y [Primeros pasos](user/es/primeros-pasos.md).
- Desarrollo: [credenciales de la API de Telegram](dev/telegram-credentials.md) y [desarrollo con varios dispositivos](dev/multi-device.md).

---

**English:** the bot-based setup (BotFather, local Bot API server, channel IDs, webhook and `.env` keys) was removed. Bento now connects to your own Telegram account by scanning a QR code; see [Connect your Telegram](user/en/connect-telegram.md). Developers: [Telegram API credentials](dev/telegram-credentials.md).
