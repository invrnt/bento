# Add a device

You can use Bento on all your computers. They all see the same library and changes arrive on their own: rename, move or delete something on one and the others follow.

## With a code (the usual way)

**On the computer that already uses Bento:**

1. Go to Settings › Devices › **Add device**.
2. You will see a large QR code, a code like `K7Q2-MXR9-T4WA` (with a copy button), a link and how much time is left.

**On the new computer:**

1. Install Bento and open it.
2. On the welcome screen, choose **I already use Bento on another device**.
3. Type the code or paste the link. If someone sent you the link through Telegram or another app, open it on this computer: the web page offers **Open Bento** with the code already filled in.
4. You will see four emojis and the message “Confirm on your other device”.

**Back on the computer that already uses Bento:**

1. You are asked: Add “Ana’s laptop · Linux”? with four emojis.
2. Check that the emojis are **the same and in the same order** as on the new computer.
3. If they match, press **Add**. If they don’t, press **Not me**: someone might be trying to sneak in.

The new computer shows “Downloading your library…” with progress, and your library appears little by little. Thumbnails arrive in the background and originals download when you open them.

### Good to know

- The code expires after 10 minutes and works once. If it expires, create another.
- If the new computer is not connected to Telegram yet, you usually don’t need to do anything else: the computer you already use authorizes it when you approve. If Telegram doesn’t allow that, the new computer shows its own Telegram QR code for you to scan with your phone.
- The code and the emojis exist so that only **your** computer can join. Bento will never ask you for the code by chat, email or phone.

## If you don’t have your other computer at hand

On the new computer, after **I already use Bento on another device**, press **I don’t have the other device**:

1. Connect your Telegram (QR code or phone number).
2. Type your [recovery kit](recovery-kit.md).
3. Bento opens your cloud and downloads your library.

This also works if you no longer have any other computer with Bento.

## If pairing with a code doesn’t work

If the code doesn’t connect (for example because a network blocks the connection), the new computer can ask for access through your Telegram:

1. On the new computer, connect your Telegram and press **Ask my other devices for access**.
2. A computer that already uses Bento shows “A new device wants to join”.
3. Check that the four emojis match on both computers and approve.

With this method, the new computer’s name and system are visible unencrypted in your “Bento · Sync” channel until it finishes. Your cloud’s keys always travel encrypted.

## Rename a device

Settings › Devices: pick the computer and change its name. The new name reaches all your computers.

## Remove a device

Do this when you sell, give away or lose a computer. From **another** computer with Bento: Settings › Devices, pick the computer and remove it. Bento:

1. Signs that computer out of Telegram. If Telegram doesn’t allow it yet (this happens when the computer you remove it from signed in recently), it tells you to end the session yourself in Telegram › Settings › Devices.
2. Changes your cloud’s keys and gives them only to the remaining computers.
3. Shows you a **new recovery kit**. Save it: the old one stops working.

Whatever the removed computer had already downloaded stays on it: it cannot be erased remotely. If you can, delete Bento and its data folder on that computer before giving it away.
